# hackathon-finder

Pipeline for finding, ranking and shipping hackathon submissions.

| File | What |
|---|---|
| [`PROJECTS.md`](PROJECTS.md) | Inventory of every existing project: specs, readiness, reusable building blocks, sponsor-track tags. Input for matching projects to hackathons. |

## Workflow

1. Inventory existing projects (`PROJECTS.md`).
2. Scan live hackathons and rank them by expected value: prize, fit, competition, rules.
3. Research the top ones' sponsors; ideate per hackathon.
4. Build specs (backend + frontend `.md`) → review.
5. Demo video (motion-storyboard) + docs → submit.
