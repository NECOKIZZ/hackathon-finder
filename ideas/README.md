## Template for new ideas

```
# NNN — Name
Status · Date captured · Origin (who/what sparked it)

1. One-liner
2. Problem (who hurts, how much, how they cope today)
3. How it works (user flow + mechanism)
4. Why now / why on-chain / why this chain
5. Competitors and what's different
6. Hackathon fit (tracks, bounties, judging angle) — one section per hackathon
7. What we can reuse from existing repos
8. MVP scope (what fits in the time we have)
9. Risks and open questions
```
