## Notes on the Oct 16 additions
- **YouCam API eCommerce (Perfect Corp):**
  - Must use at least 1 YouCam API in a working web or mobile prototype. Submit a repo, a description and a 1–3 minute video. Each participant gets 1,000 free API units.
  - Judged on tech, design, impact and the idea.
  - **About 900+ registered**, so competition is heavy.
  - Fits Cuerate-style AI image work, but it isn't web3.
- **X Layer TapeOut Accelerate (Oct 16 – Dec 7):**
  - Projects must be **built inside the TapeOut ecosystem**: use TapeOut circuits, contracts or on-chain data on X Layer, or run on X Layer DeWEB.
  - Existing projects count only with substantial new work.
  - Prizes are **paid in milestone stages**, and an offline Demo Day is held for the shortlist.
  - Note: TapeOut Genesis was ⛔ in October as a "token launchpad". This program is wider (apps, games, tools, circuits).
  - **Possible fits:** the Cuerate RE Agent (already on OKX / X Layer), or Chog City / Archer-style games using TapeOut contracts.
  - Judged on user value and commercial potential, innovation, ecosystem integration, readiness, and a ≤3 minute demo.
